ПРИЛОЖЕНИЕ ДЛЯ macOS

Облачные файлы
в Finder

MyClouds подключает облачные хранилища к macOS с помощью rclone и macFUSE.

Combine

Каждое облако — отдельная папка на общем диске.

Union

Файлы облаков — в общем пространстве. Для создания новых файлов используется политика выбора облака с наибольшим свободным местом.

Google Drive

Авторизация проходит в браузере Google. Разрешение на доступ к Google Drive нужно для просмотра и чтения существующих файлов, а также создания, изменения, переименования и удаления файлов по вашим действиям.

Хранение настроек

Конфигурация rclone хранится на вашем Mac в зашифрованном виде; ключ хранится в Связке ключей macOS. Для работы с файлами приложение использует локальный кэш.

Подробности: политика конфиденциальности.
