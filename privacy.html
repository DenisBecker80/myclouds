Назначение приложения

MyClouds — приложение Дениса Беккера для доступа к подключённым пользователем облачным хранилищам через Finder. Передача файлов выполняется с помощью rclone.

Какие данные используются

Для работы с облаками приложение использует данные авторизации, названия и содержимое файлов, папки и их метаданные. При подключении Google Drive вход выполняется на странице Google в браузере; приложение использует полученные OAuth-токены для разрешённых операций.

Для чего нужен доступ к Google Drive

Доступ используется для отображения папок, чтения, создания, изменения, переименования и удаления файлов по действиям пользователя. Работа с существующими файлами требует доступа к файлам, созданным вне MyClouds.

Где хранятся данные

Настройки и данные авторизации находятся в зашифрованной конфигурации rclone на Mac пользователя. Ключ шифрования хранится в Связке ключей macOS. Кэш файлов и журналы работы сохраняются локально и не шифруются самим MyClouds.

Передача данных

rclone взаимодействует с подключёнными облачными сервисами. В режиме Union новые файлы могут записываться в любое из включённых пользователем облаков согласно выбранной политике. Приложение не отправляет файлы или токены на сервер разработчика.

Данные Google не используются для рекламы, продажи или обучения моделей. Использование и передача информации, полученной через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Отключение доступа и удаление

Доступ MyClouds к Google Drive можно отозвать в настройках Google-аккаунта. После завершения передач можно удалить локальные настройки, кэш и ключ из Связки ключей. Отзыв доступа и удаление приложения не удаляют файлы из облачных хранилищ.

Сайт и обращения

Сайт размещён на GitHub Pages. Обработка данных посетителей платформой описана в политике конфиденциальности GitHub. По вопросам приложения можно создать обращение на GitHub. Обращения в публичном репозитории видны всем: не публикуйте там пароли, токены или личные файлы.
